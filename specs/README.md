# Throne spec

One file per feature or module of throne, grouped by area folder: `messaging`, `runtime`, `agents`, `delivery`, `queue`, `platform`, `knowledge` and `web`. Each file follows the form in `agent_docs/spec-form.md` and is written by the steps in `agent_docs/spec-writing-steps.md`. Every public command is claimed by the spec file whose search words name it.

`FEATURE_MAP.md` is generated by `throne feature-map specs --registry throne`; never edit it by hand. `ERRATA.md` lists places where the code and the spec knowingly disagree.

Flags, exit codes and detailed behaviour of each command stay in `agent_docs/commands.md`; the spec states what each feature does and how to prove it.
