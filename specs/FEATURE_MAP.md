# Feature map

Generated by `throne feature-map` from the spec file headers. Do not edit it by hand; run the command again.
Covered areas: agents, delivery, knowledge, messaging, platform, queue, runtime, web.
Everything else is uncatalogued: search the code for it.

## agents

- **Agent state file**: Records each agent's declared state (working, blocked, waiting on its own run, waiting on its supervisor, reapable) in one file that every state check reads instead of the agent's pane. ([agents/agent-state.md](agents/agent-state.md))
- **Model and persona switching**: Moves a live agent to another model of the same family, or switches the court persona. ([agents/agent-steering.md](agents/agent-steering.md))
- **Agent completion and reaping**: Verifies an agent finished and tears it down. ([agents/completion.md](agents/completion.md))
- **Agent creation**: Spawns a new harness in herdr with a validated identity, model and spawn evidence. ([agents/create-agent.md](agents/create-agent.md))
- **Idle and nudge watchdogs**: Nudges stalled agents, pages about idle families and untasked agents, wakes agents waiting on their own background run, and presses Enter on drafts stuck in an agent input box. ([agents/watchdogs.md](agents/watchdogs.md))

## delivery

- **Delivery verification**: Proves from git state alone that work landed, and guards protected branches. ([delivery/verification.md](delivery/verification.md))
- **Worktrees and merges**: Creates campaign worktrees and merges slice branches back into their target. ([delivery/worktrees.md](delivery/worktrees.md))

## knowledge

- **Finding and sifting**: Ranks files and items by relevance and trims long command output to what matters. ([knowledge/finding.md](knowledge/finding.md))
- **Memory and skill extensions**: Finds each project's memory directory, recalls memories for a task, and prints operator skill extensions. ([knowledge/memory.md](knowledge/memory.md))
- **Specs and feature map**: Locates a repository's spec and feature map, generates the map and checks the spec set. ([knowledge/specs.md](knowledge/specs.md))

## messaging

- **Message queue**: Stores every message durably in SQLite and lets senders track, cancel, read and acknowledge it. ([messaging/message-queue.md](messaging/message-queue.md))
- **Agent messaging**: Delivers one message to a named agent pane, wrapped in its queue id tags, without overwriting a draft the pane already holds, can force a bare Enter into that pane, and takes over a pane lock held longer than a minute. ([messaging/send-agent.md](messaging/send-agent.md))

## platform

- **Throne lifecycle**: Installs, starts, stops and restarts the throne and its Regent. ([platform/lifecycle.md](platform/lifecycle.md))
- **Notifications and bots**: Sends messages to the Lord through ntfy and through Matrix bots. ([platform/notifications.md](platform/notifications.md))
- **Regent fencing and suite arbitration**: Hands context to a freshly summoned Regent and records who holds the full suite. ([platform/regent-fencing.md](platform/regent-fencing.md))
- **Scratch space and slots**: Sweeps stale scratch directories and runs commands in counted slots. ([platform/scratch.md](platform/scratch.md))
- **Identity, forge and previews**: Supplies the git identity, works with pull requests, publishes tailnet previews and checks pinned tools. ([platform/tooling.md](platform/tooling.md))
- **Usage and capacity**: Reports plan usage, token lanes, host pressure and the Claude accounts agents run on. ([platform/usage.md](platform/usage.md))

## queue

- **Queue amendments**: Records the Lord's amendments on a queue row and refuses merging past an unreconciled one. ([queue/amendments.md](queue/amendments.md))
- **Campaign launch**: Prepares a queue row for launch and briefs the new Alpha. ([queue/launch.md](queue/launch.md))
- **Regent queue store**: Keeps the Regent queue of objectives in SQLite and lets the court add, edit, defer, release and archive rows. ([queue/queue-store.md](queue/queue-store.md))
- **Where I stand**: Agents write the Lord's where-i-stand page as tabs, sections and rows in the where-i-stand database through commands; check-where-i-stand and work-log read it. ([queue/where-i-stand.md](queue/where-i-stand.md))

## runtime

- **Agent observation**: Shows which agents are alive, what they print, and how long they take. ([runtime/agent-observation.md](runtime/agent-observation.md))
- **Alpha autoscale**: Spawns Alphas for launch-eligible queue rows on a schedule or on demand. ([runtime/autoscale.md](runtime/autoscale.md))
- **Throne backend**: Runs the long-lived server that hosts the message dispatch loop, the watchdogs and the web listener. ([runtime/backend.md](runtime/backend.md))
- **Throne database**: Opens the where-i-stand and lock SQLite databases through Drizzle, applies its committed migrations in process, and refuses a schema no migration covers. ([runtime/database.md](runtime/database.md))
- **Lock rows**: Holds every cross-process lock throne takes as a row in one SQLite file, freed when its holder dies, with no dependency on flock. ([runtime/lock-rows.md](runtime/lock-rows.md))

## web

- **Web app**: Serves one React app with a route per tool on loopback and publishes it on the tailnet. ([web/web-app.md](web/web-app.md))
- **Where-i-stand page**: The web app's where-i-stand route shows the database's tabs, sections and rows below the Lord's pull request table, lets him edit his epics, and archive or restore any row or section. ([web/where-i-stand-page.md](web/where-i-stand-page.md))
